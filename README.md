# Creative Homogenization in Diffusion-Generated Gift Designs

A small, reproducible pilot that asks one question: **when a text-to-image diffusion model is free to choose, is its output less diverse than a human designer's?**

The human set is 30 handcrafted gift designs (baskets, bouquets, boxes, acrylic boxes, cards) from my own gifting business. The AI sets are generated by Stable Diffusion XL under fixed seeds. Diversity is measured in CLIP embedding space.

## Key results

All results below use background-removed images (see [Controlling for photography](#1-controlling-for-photography)).

| AI condition | Prompt given to the model | Vendi score, AI | Vendi score, human | Gap | Permutation p |
|---|---|---|---|---|---|
| Detailed | Full description of the matched human design | 4.35 | 4.09 | none | 0.76 |
| Category | Product type only, e.g. "A handmade gift basket" | 3.33 | 4.09 | 18% lower | 0.011 |
| Open | One fixed brief, 30 seeds | 2.83 | 4.09 | 31% lower | 0.001 |

Mean pairwise cosine distance shows the same pattern (human 0.286; AI 0.301 / 0.252 / 0.203; p = 0.75 / 0.051 / 0.001).

**Finding:** the model matches human diversity when the brief specifies the design, and loses diversity monotonically as it is given more freedom. The effect was only measurable after removing a photographic confound.

## Experiments

### 1. Controlling for photography

The first comparison used raw photographs and matched detailed prompts.

| Images | Vendi, human | Vendi, AI | Permutation p |
|---|---|---|---|
| Raw photographs | 5.35 | 4.54 | 0.066 |
| Backgrounds removed | 4.09 | 4.35 | 0.76 |

The 15% gap on raw photographs disappeared once backgrounds were removed. Human photos were taken in real rooms with hands and uneven lighting; generated images are clean renders. CLIP encoded that difference. Every result in the key table therefore uses cut-out images centred on a white canvas.

### 2. Varying the model's freedom

Two further AI sets were generated, each with 30 images:

- **Category:** each prompt states only the product type of the matched human design, preserving the human set's category mix (11 baskets, 4 bouquets, 3 sets of mini bouquets, and so on).
- **Open:** every image uses the same brief, "A handmade gift arrangement from a small gifting business, product photograph", with a different seed.

## Method

| Step | Choice |
|---|---|
| Generator | `stabilityai/stable-diffusion-xl-base-1.0`, fp16, 30 steps, guidance 7.0 |
| Seeds | Detailed: 1000 + id; Category: 3000 + id; Open: 2000 + id |
| Background removal | `rembg` (U²-Net), cropped to the object, centred on a 512 × 512 white canvas with a 6% margin |
| Embedding | CLIP `ViT-B-32-quickgelu`, OpenAI weights, L2-normalised |
| Diversity metrics | Vendi score (exponentiated entropy of the eigenvalues of the cosine similarity kernel divided by n); mean pairwise cosine distance |
| Uncertainty | 5th to 95th percentile over 1,000 random subsets of 80% of each set, drawn without replacement |
| Significance | One-sided permutation test, 5,000 label shuffles, hypothesis: human more diverse than AI |
| Visualisation | UMAP with cosine metric, `n_neighbors` = 5, 10, 15, `random_state` = 42 (illustrative only) |

## Reproducing

**1. Generate images** in Google Colab with a T4 GPU. Open each notebook, set the runtime to GPU, and run all cells. Each notebook writes its generation settings to a JSON file alongside the images.

**2. Set up the analysis environment** (CPU is sufficient):

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; use source .venv/bin/activate on macOS/Linux
pip install torch open_clip_torch umap-learn matplotlib pillow numpy "rembg[cpu]"
```

**3. Remove backgrounds:**

```bash
python remove_backgrounds.py
python remove_backgrounds.py data/ai_category data/ai_open
```

**4. Run the comparisons:**

```bash
python analyze_diversity.py                                                        # raw photographs
python analyze_diversity.py --human data_nobg/human --ai data_nobg/ai --tag nobg
python analyze_diversity.py --human data_nobg/human --ai data_nobg/ai_category --tag category
python analyze_diversity.py --human data_nobg/human --ai data_nobg/ai_open --tag open
```

Each run writes `results_<tag>.json` and `umap_<tag>.png`. Images are paired by the number in their file name; unpaired ids are skipped.

## Limitations

- **Small sample:** one human designer, one generator, 30 images per set, one image per prompt.
- **Different production conditions:** human designs were made over time for different clients and occasions; AI images were generated in a single session.
- **Embedding choice:** CLIP ViT-B/32 may not capture fine material details such as ribbon texture, handwriting or fabric.
- **Background removal:** U²-Net occasionally keeps hands or trims thin elements such as tulle; cut-outs were inspected visually but not corrected.
- **Multiple comparisons:** three AI conditions were tested against one human set. The Category and Open results remain below 0.05 after Bonferroni correction for three tests (0.033 and 0.004).

## Next steps

- Repeat with several seeds per prompt and a second generator to separate model behaviour from sampling noise.
- Validate the embedding metric against human judgements of design similarity.
- Test diversity-aware sampling and re-ranking as interventions.
